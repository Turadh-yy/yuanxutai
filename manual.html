一、圆序台是什么

圆序台是一个「个人 / 家庭数字工作台」，把日常零散的事——家里有什么东西、冰箱里还剩什么、这周吃什么、要买啥、有什么事待办、钱花在哪——都收进一个页面里管。

📦
物品管理
家里物品清单 + 分类
🧊
冰箱管理
食材保质期提醒
🍳
菜谱
本周食谱 + 菜谱库
🛒
购物清单
要买的东西
✅
事件待办
事情不落
💰
记账本
收支 + 分类 + 月度
特点：单文件、零依赖、数据存本地浏览器；可安装到手机桌面像 App 一样用；开通云同步后多设备数据互通。

二、开始使用

2.1 打开网址

手机或电脑浏览器打开：

https://turadh-yy.github.io/yuanxutai/

注意：不要在微信里直接打开（微信内浏览器装不了 App）。点右上角「···」→「在浏览器打开」，用系统浏览器（Safari / Chrome / Edge）继续。

2.2 安装到桌面（像 App 一样用）

圆序台支持 PWA，可以「安装」到手机 / 电脑桌面，之后像原生 App 一样全屏打开、离线可用。

  • 安卓（Chrome / Edge）：打开网址后，地址栏或页面底部会出现「安装 / 添加到主屏幕」提示，点一下即可；或在菜单里选「添加到主屏幕」。
  • 苹果 iOS（Safari）：点底部分享按钮 ⬆️ →「添加到主屏幕」。
  • 电脑（Chrome / Edge）：地址栏右侧会出现安装图标，点一下；或菜单→「安装此应用」。
没装也能用：不安装、直接用浏览器打开网址也完全正常，只是没有桌面图标、不能全屏。装了之后每次从桌面图标进，体验更像 App。

2.3 注册与登录

第一次用要先注册一个账号（数据按账号隔离）：

  1. 打开页面后，登录界面下方点「注册」
  2. 用户名 2–16 位（不能和别人重复），密码 6 位数字
  3. 填好点「注册」，注册成功会自动登录
  4. 以后每次打开，输用户名 + 密码「登录」即可
记好用户名和密码：密码只存在你自己的设备上，忘了就只能重新注册一个新账号（旧数据找不回）。建议把用户名 / 密码记在安全的地方。

三、功能模块

顶部 6 个大卡片切换不同模块（卡片上方有文字提示，点一下就切换；第一次进入会有导览弹窗，点「我知道了」后不再出现），下面逐个说明。

页面太长怎么办：每个模块的列表都设了显示高度上限，内容多时在框内上下滑动即可，不会把整页撑得老长。浏览中想回到最上面，点屏幕右下角的圆形「返回顶部」按钮，一下就回顶。

3.1 日历 · 今日待办 · 记账概览

页面最上方三栏（手机端会自适应重排，优先显示今日待办）：

  • 日历：看日期、月份切换；记过账的日期会有标记。
  • 今日待办：今天到期 / 未完成的事，一眼看见今天要干什么。
  • 记账柱形图：本月收支一览，哪天花多少看得见。

3.2 物品管理

管理家里的物品清单。

  • 添加物品：填物品名称 + 分类，保存。
  • 编辑物品：想改某条记录，点它卡片上的「编辑」按钮，原内容会回填到输入框，改好后点「保存修改」；不想改了点「取消编辑」。不要的记录点「删除」即可。
  • 智能识别：系统内置常用物品字典，输入时会自动匹配分类，省得自己归类。
  • 用途：知道家里有什么、放在哪、多少，搬家 / 整理 / 找东西时不用翻箱倒柜。

3.3 冰箱管理

管冰箱里的食材，重点是保质期。

  • 添加食材：名称 + 数量 + 保质期日期。
  • 编辑食材：点卡片上的「编辑」按钮可改名称、数量或保质期，改完点「保存修改」；删掉某条点「删除」。
  • 过期提醒：临期 / 已过期的会高亮提示，避免吃到坏东西、减少浪费。
  • 和菜谱联动：菜谱用到某食材时，能查到冰箱里还有没有、哪天到期。

3.4 菜谱（本周食谱 / 今日推荐 / 菜谱库 / 新建）

管「这周吃什么」「今天推荐做啥」和「会做哪些菜」。

  • 本周食谱：按天 / 餐安排要做的菜，一餐可以配多个菜谱。
  • 今日食谱推荐：按「冰箱里有什么 + 临期食材」打分自动推荐，默认只看前 4 道，想看更多就点下方「查看更多 ↓（还有 N 道）」按钮；展开后按钮变「收起 ↑」，再点回到 4 道。输入框可按菜名 / 食材 / 分类搜索，搜索时折叠态会自动复位。
  • 菜谱库：收藏的所有菜谱，可按菜名 / 食材 / 分类搜索。同样默认先看 4 道，有更多时底部出现「查看更多」按钮，逻辑同上。
  • 新建菜谱：填菜名 + 分类 + 食材 + 步骤，存进菜谱库，以后排食谱直接选。
  • 菜谱详情：点菜谱看食材、步骤；可直接把所需食材加到购物清单。

3.5 购物清单

要买的东西列在这里。

  • 从菜谱详情「加入购物清单」，或手动添加。
  • 买一样勾一样，买完自动清理，清单干净不乱。

3.6 事件待办

事情别落下。

  • 添加待办事项，可设日期。
  • 今天到期的会出现在顶部「今日待办」栏。
  • 做完打勾，自动归档。

3.7 记账本

记收支，知道钱花哪了。

  • 支出 / 收入：顶部切换记的是花钱还是进钱。
  • 分类：如购物、餐饮等，按类统计。
  • 月份选择：看某月记录，月份切换条上下翻。
  • 柱形图：顶部三栏里的记账图按日汇总，哪天花多少一目了然。
  • 支持编辑、删除已有记录。

四、数据与同步

4.1 云同步（多设备互通）

默认数据只存在当前浏览器里。开通云同步后，手机和电脑、甚至家人朋友之间数据可以互通。

  1. 登录后，点「云同步」（电脑在页面右上角；手机端点右上角「☰ 更多」，在弹出菜单里选「云同步」）
  2. 把 GitHub Token 粘进输入框
  3. 点「保存并验证」（显示「验证通过」就成）
  4. 点「立即同步」，本地数据上传云端
之后：不用再管，打开应用自动拉取云端最新，改完约 10 秒自动推送。多台设备都配一次，数据就互通了。
每人数据独立：每个用户的数据在云端是独立文件（按用户名区分），互不覆盖。

4.2 导出备份与导入恢复

「导出备份」可把当前用户全部数据导出成一个 Excel（.xlsx）文件，文件名形如 圆序台_用户名_日期.xlsx，含多个工作表。（电脑在页面右上角；手机端在右上角「☰ 更多」菜单里）

  • 导出：点「导出备份」→ 浏览器自动下载 .xlsx。
  • 导入：点「导入」（或选文件），选 .xlsx / .json / .csv 文件，数据恢复进来。兼容旧版 .json 备份。
建议：定期导出一份备份存到电脑 / 网盘，万一清了浏览器数据或换设备，数据找得回。

五、账号与管理员

5.1 多用户数据隔离

一台设备可以注册多个账号，每个账号的数据互相看不到、改不到。数据按账号前缀分开存储。退出登录（电脑在页面右上角；手机端在右上角「☰ 更多」菜单底部）后可以换账号登录。

5.2 管理员查看他人数据

管理员账号是保留用户名 Turadh。首次使用应用时，会引导为管理员设置登录密码（不再内置默认密码，请务必记牢）。管理员可以查看其他用户的数据，方便家庭场景里看家人记的东西。

  • 管理员登录后，可切换查看其他用户的数据。
  • 查看他人数据时，顶部会有提示条，标明当前在看谁的数据。
  • 查看他人数据期间，同步会暂停（避免把别人的数据误推到自己账号）。
安全建议：管理员能看所有用户数据，家庭共用场景建议设置高强度密码并妥善保管。

六、给家人朋友共用

圆序台支持「共享一个细粒度 Token」的方式，让信任的家人朋友也用上云同步。每人用自己的账号登录，数据按用户名在云端独立存放，互不覆盖。

由仓库主人一次性准备（建共享 Token）

  1. 打开 https://github.com/settings/personal-access-tokens/new （需登录你的 GitHub）
  2. Token name：随便起，如「圆序台共享」
  3. Expiration：按需（如 90 天 / 1 年，到期要换）
  4. Repository access：选「Only select repositories」→ 只勾 yuanxutai-data
  5. Repository permissions：点「+ Add permissions」→ 找到 Contents → 勾上 → 右侧 Access 选 Read and write（其余保持 No access）
  6. 点「Generate token」，复制 github_pat_ 开头的那串，私发给信任的人
关键：Permissions 区不能空，必须给 Contents: Read and write，否则 token 访问仓库会报 404（看着像仓库不存在，其实是没权限）。

给朋友的操作步骤

  1. 手机 / 电脑浏览器打开 https://turadh-yy.github.io/yuanxutai/
  2. 注册一个用户名（2–16 位，不重复）、设 6 位数字密码
  3. 登录后点顶部「云同步」
  4. 把 Token 粘进输入框，点「保存并验证」
  5. 点「立即同步」
之后：不用再管，自动拉取 / 推送。多设备都配一次即互通。

隐私须知

持 Token 者能读取仓库里所有人的数据文件（含记账金额等）。所以只发给信任的人；介意互相看到记账的，别用共享方式。Token 不要发到公开群、不要提交进任何仓库。

七、常见问题

Q：手机打开没提示安装？

A：圆序台检测到未安装时每次打开都会弹安装提示。微信里打不开——点「···」→「在浏览器打开」再用。苹果走 Safari 分享→添加到主屏幕。安卓 Chrome 直接有安装提示或菜单添加。

Q：换了手机 / 清了浏览器，数据没了？

A：数据默认存在本地浏览器，换设备或清缓存会丢。两个办法找回：① 开了云同步，新设备登录同一账号 + 配同一 Token 即可拉回；② 之前导出过 .xlsx 备份，点「导入」恢复。

Q：云同步点了「立即同步」没反应 / 数据没更新？

A：GitHub 云端写入后有 1–2 秒的延迟。刚在 A 设备改完，B 设备立刻拉可能拿到上一版；过几秒再点一次「立即同步」就是最新。不会丢数据。

Q：忘了密码怎么办？

A：密码只存本地，找不回。只能重新注册一个新账号（旧账号的数据若开了云同步，仍可通过云同步在新设备拉回——需用同一 Token）。

Q：Token 怎么获得？

A：见第六章。需在 GitHub 网页本人创建，无 API 可代生成。

八、安全与撤销

  • 撤销共享 Token：到 https://github.com/settings/personal-access-tokens 找到对应 Token，点「Revoke」即可。撤销后所有人的同步失效（但他们设备上已存的本地数据不受影响）。
  • Token 泄露过：如果 Token 在聊天 / 截图里明文出现过，建议到 GitHub 点「Regenerate」换个新值再分发，旧的作废。
  • 管理员密码：首次使用时引导设置（无默认密码），请设置高强度密码并牢记。
  • 定期备份：即便有云同步，也建议偶尔「导出备份」一份存本地 / 网盘，双保险。
