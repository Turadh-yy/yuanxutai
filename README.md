# 圆序台 · 个人数字工作台

单文件 HTML 个人工作台，零外部依赖（无 CDN / 无框架 / 无字体），数据全部存储在浏览器 localStorage。

## 功能模块
- 物品管理（日耗品/周期品/耐用品/应急品四分类）
- 冰箱管理（保质期追踪、临期提醒、智能存储建议）
- 本周食谱（今日推荐 ≤20、菜谱库 48 道、保质期冲突提醒）
- 购买清单（食谱联动）
- 事件待办（按日期排序）
- 记账本（按月统计、分类图表）

## 使用说明
- 数据存在浏览器本地，刷新/关闭不丢失
- 首屏提供「导出 JSON 备份 / 导入恢复」
- 手机浏览器打开可「添加到主屏幕」当 App 用
